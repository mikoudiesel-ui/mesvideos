# Plus malin que le diable : script de la pub Facebook

## Décisions de production

- **Format** : 9:16 vertical, 1080x1920 (Reels, Stories, et le fil en recadrage 4:5). C'est le format qui coûte le
  moins cher à l'affichage et qui accroche le plus sur Facebook et Instagram.
- **Durée** : environ 32 s (environ 24 s de voix, un gag muet, une pause sur fond noir, l'écran de fin).
- **Les 3 premières secondes décident de tout** : le premier mot nomme la douleur, une image forte dès la première
  image, jamais le logo.
- **Lisible sans le son** : 85 % des pubs Facebook sont vues en muet, donc le sous-titre mot par mot porte tout le film.
- **Ton** : sombre et intime au début (la petite voix qui sabote), lumineux et franc après la bascule.
- **Pas de promesse chiffrée ni de témoignage inventé** : Facebook refuse les promesses de résultat non prouvées.

## Les 7 idées d'accroche

1. **La semaine qui file** : « Lundi, tu te promets de commencer… Dimanche, rien n'a bougé. » Fin : « Sois plus malin
   que lui. »
2. **Le diable parle à la première personne** : « Moi, je ne te fais pas peur. Je te fais juste… attendre. » Fin : le
   diable se fait démasquer.
3. **La notification du diable** : un téléphone reçoit des messages « Pas aujourd'hui », « T'es pas prêt ». Fin :
   « Bloque-le. »
4. **Le contrat** : une signature au bas d'un contrat « Je commence demain ». Fin : « Déchire le contrat. »
5. **Les ruses démasquées** : chaque excuse est une carte qui se retourne et montre sa vraie face. Fin : « Tu connais
   ses ruses. Il a perdu. »
6. **Le réveil de 3 h** : le plafond, les pensées qui tournent. Fin : « Cette nuit, c'est toi qui gagnes. »
7. **La partie d'échecs** : tu joues contre une ombre qui a toujours un coup d'avance, jusqu'au retournement. Fin :
   « Échec et mat. »

Je retiens **1** (le plus universel, la douleur la plus reconnaissable) et **2** (le plus intrigant, le plus
« arrête-pouce »). Les deux sont écrits en entier ci-dessous.

## Version A : « La semaine qui file » (recommandée pour la publicité)

### Version mise en scène

| Partie | Voix | À l'écran |
|---|---|---|
| 1. Accroche datée | Lundi, tu te promets de commencer. | Un calendrier, « Lundi » entouré, une liste « Commencer » |
| | Mercredi, tu repousses. | La case « Commencer » glisse sur jeudi, puis vendredi |
| | Dimanche soir… rien n'a bougé. | La case vide, la page du dimanche qui se tourne |
| 2. Gag muet (2,5 s) | *(silence)* | Le réveil du lundi suivant sonne, un doigt appuie sur « Répéter » ; une ombre à cornes sourit dans le reflet de l'écran |
| 3. Diagnostic | Ce n'est pas un manque de talent. | |
| | C'est une petite voix. | L'ombre derrière l'épaule |
| | Elle te dit d'attendre. | [boîte : attendre] |
| | Que ce n'est pas pour toi. | [boîte : pas pour toi] |
| | Que demain, ce sera mieux. | [boîte : demain] |
| 4. Bascule sur noir | Et si tu étais plus malin qu'elle ? | Phrase centrée sur fond noir, 1,5 s de silence |
| 5. Solution | Plus malin que le diable. | La couverture de l'ebook arrive de la caméra, floue puis nette |
| | Un ebook qui démasque ses ruses, une par une. | Les pages défilent, chaque excuse barrée [trait : ruses] |
| | Et te donne de quoi lui répondre. | La liste « Commencer » se coche enfin |
| 6. Marque et appel à l'action | Télécharge-le maintenant. Le lien est juste en dessous. | Couverture, bouton « Télécharger l'ebook », curseur qui clique ; le calendrier du début revient, lundi coché |

Environ 64 mots de voix, soit environ 22 s de parole.

## Version B : « Le diable parle »

### Version mise en scène

| Partie | Voix | À l'écran |
|---|---|---|
| 1. Accroche | Moi, je ne te fais pas peur. | Noir, une silhouette à cornes se dessine en fumée |
| | Je te fais juste… attendre. | Une horloge, l'aiguille qui saute des heures |
| | Un projet ? Plus tard. | [boîte : plus tard] une note « Mon projet » qui s'efface |
| | Un rêve ? Pas maintenant. | [boîte : pas maintenant] une porte qui se referme |
| 2. Gag muet (2,5 s) | *(silence)* | Le diable pose un « Demain » en post-it sur l'écran du téléphone ; une main l'arrache |
| 3. Diagnostic | Tu crois que c'est de la paresse. | |
| | C'est moi. | [trait : moi] |
| | Et je gagne chaque fois que tu doutes. | [boîte : doutes] |
| 4. Bascule sur noir | Sauf si tu connais mes ruses. | Phrase centrée sur noir, la fumée se dissipe, 1,5 s de silence |
| 5. Solution | Plus malin que le diable. | La couverture de l'ebook déchire le noir |
| | L'ebook qui les démasque, une par une. | Les excuses barrées une à une |
| | Pour que, cette fois, ce soit toi qui gagnes. | [trait : toi] |
| 6. Marque et appel à l'action | Télécharge-le maintenant. Le lien est juste en dessous. | Couverture, bouton, curseur qui clique ; le post-it « Demain » revient, froissé |

Environ 62 mots. Idéalement deux voix : une voix grave pour le diable (parties 1 à 4), une voix franche pour la
solution (parties 5 et 6). Une seule voix fonctionne aussi.
