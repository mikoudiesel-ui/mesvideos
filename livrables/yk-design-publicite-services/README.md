# Publicité Y-K Design — dossier pour Claude Code

17 scènes pour promouvoir les montages publicitaires en motion design destinés aux boutiques. Monogramme YK, trois concepts publicitaires et contact fourni : **+225 07 12 35 46 02**.

[Télécharger le dossier ZIP](DOSSIER_YK_DESIGN_CLAUDE.zip) · [Lire le prompt complet](PROMPT_CLAUDE_CODE.md) · [Voir le plan PDF](PLAN_DE_PRODUCTION.pdf)

Le ZIP contient 62 fichiers : 17 maquettes, les affiches et le monogramme séparés, les polices, l’audio aligné, la vidéo de référence, les consignes par scène, le PDF, le lecteur HTML et le prompt complet. Ce dossier prépare la réalisation dans Claude Code ; il ne contient pas encore la vidéo motion design finale.

1. Télécharger et extraire le ZIP entier.
2. Ouvrir DOSSIER_YK_DESIGN_CLAUDE comme dossier de projet dans Claude Code.
3. Copier PROMPT_CLAUDE_CODE.md dans Claude, ou utiliser DEMARRER_DANS_CLAUDE.txt.
4. Claude réalisera et rendra le master décrit : 1920×1080, 30 i/s, 623 images, 20,7666667 secondes.

Pour consulter les maquettes, ouvrir PLAN_DE_PRODUCTION.pdf. Le lecteur LECTEUR_STORYBOARD.html fonctionne après décompression et affiche les images fixes sur le son. Le fichier audio de rendu est AUDIO_MASTER.wav, sans modification de vitesse ni ajout de bruitages.

L’archive a été vérifiée par CRC et par empreinte SHA-256 des fichiers. Les 17 plages sont contiguës ; l’audio possède 996 800 échantillons par canal à 48 kHz. Le PDF a 18 pages et le lecteur a été vérifié sur les 17 choix de scène.
