# Référence Pinterest — motion design pour d’autres entreprises

La référence fournie par l’utilisateur est une publicité Pinterest de 20,7667 secondes, en 16:9, à 30 images/seconde. Ce dossier détaille ses 17 séquences et fournit un prompt pour Claude Code afin d’en reprendre la mécanique avec une autre entreprise.

## Télécharger et utiliser

1. Ouvrir [le ZIP](./DOSSIER_REFERENCE_PINTEREST_CLAUDE.zip), puis cliquer sur « Download raw file » dans GitHub.
2. Décompresser le dossier et ouvrir `LECTEUR_ANALYSE.html` ou `PLAN_VISUEL.pdf`.
3. Remplir `BRIEF_ENTREPRISE.json` avec la nouvelle marque.
4. Placer le dossier dans le projet utilisé par Claude Code, puis copier le contenu de `PROMPT_MAITRE_CLAUDE_CODE.md` dans sa conversation.

Le ZIP comprend les captures, la vidéo de référence, le mix AAC extrait sans réencodage et un WAV aligné sur la durée du film, atténué uniformément de 4,1 dB. Les timings et la vitesse de lecture sont conservés. Aucun nouveau film publicitaire rendu n’est inclus.

Les valeurs de cadrage raster et plusieurs départs de gestes sont approximatifs. Les grandes coupes sont repérées à la frame ; le BPM musical, la police, les sons isolés et les courbes d’auteur ne sont pas certifiés. Le prompt préserve la piste originale plutôt que d’inventer leur reconstruction.
