# Dossier motion design — Bikinis shop @daya_na990

Le ZIP réunit 14 images de scène, quatre planches, un PDF de production, une galerie consultable hors ligne, le minutage, un son témoin et le prompt pour Claude Code.

## Télécharger

Ouvrir [DOSSIER_CLAUDE_DAYA_14_SCENES.zip](./DOSSIER_CLAUDE_DAYA_14_SCENES.zip), puis utiliser « Download raw file » sur GitHub pour enregistrer le ZIP sur votre ordinateur.

## Utiliser avec Claude Code

1. Décompresser le ZIP.
2. Ouvrir le dossier décompressé dans le projet utilisé par Claude Code.
3. Copier le contenu de `PROMPT_CLAUDE_CODE.md` dans Claude Code.
4. Fournir les photos originales des articles pour obtenir une publicité fidèle au catalogue.

Le prompt est aussi disponible [séparément](./PROMPT_CLAUDE_CODE.md).

Durée prévue : 26,4667 secondes, 794 images à 30 images/seconde, format de réalisation 1080 × 1920.

Les visuels sont des maquettes illustratives. Le ZIP prépare la réalisation de la vidéo ; il ne contient pas le film final de ces quatorze scènes.
